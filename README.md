# Sample Hardhat Project

This project demonstrates a basic Hardhat use case. It comes with a sample contract, a test for that contract, and a Hardhat Ignition module that deploys that contract.

Try running some of the following tasks:

```shell
npx hardhat help
npx hardhat test
REPORT_GAS=true npx hardhat test
npx hardhat node
npx hardhat ignition deploy ./ignition/modules/Lock.ts

npm init -y
npm install --save-dev @nomicfoundation/hardhat-toolbox@6.1.0      
npm install --save-dev hardhat@2.26.3 prettier@3.6.2
npm install --save-dev --legacy-peer-deps axios@1.12.2
npm install --save-dev dotenv@17.2.2 ethers@6.15.0
npm install --save-dev inquirer@12.9.6
npm install --save-dev chalk
npm install --save-dev typescript
npm install @openzeppelin/contracts@^4.9.0
npm shrinkwrap
npx hardhat


```
